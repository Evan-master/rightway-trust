Application Purpose & Core Features

Polaris Agent Desktop Email & Coding Workspace

A native macOS desktop application developed by RightWay AI. Users manage local software projects, run developer workflows, and optionally connect their Gmail or Microsoft Outlook mailbox via OAuth 2.0 PKCE to search messages, triage threads, prepare drafts, and send user-approved emails directly on their Mac.

RightWay One Academic Planning

Structured college preparation software that helps students and families plan coursework, track application milestones, organize writing drafts, and coordinate counseling tasks with verified Google OAuth account identity.

RightWay School OS

Academic advising operations software for partner schools and counselors to coordinate advising schedules, student progress records, and application timelines with role-based security controls.

Why RightWay AI Requests Google User Data

RightWay AI accesses Google APIs strictly on an opt-in basis to deliver user-requested identity and email productivity features:

  • Identity & Profile (openid, userinfo.email, userinfo.profile): Verifies your Google account identity and displays your name, email address, and profile avatar within RightWay AI applications.
  • Email Client & Productivity (gmail.modify, gmail.compose, gmail.send): Used only when you explicitly connect Gmail inside the Polaris Agent macOS desktop application so you can search and read messages, update thread labels, save drafts for review, and send emails after your explicit confirmation.
  • Local macOS Keychain Token Storage: Desktop Gmail OAuth tokens are encrypted locally in your computer's macOS Keychain and are never stored on RightWay AI cloud servers.
  • Google API Services User Data Policy Compliance: RightWay AI's use and transfer to any other app of information received from Google APIs adheres strictly to the Google API Services User Data Policy, including the Limited Use requirements. RightWay AI never sells user data, never uses Google data for advertising, and never uses Gmail content to train generalized AI models.

Google API Terms of Service & Responsible Text Productivity

RightWay AI is exclusively a text-based software engineering, email productivity, and educational planning toolset, and complies fully with the Google API Terms of Service. RightWay AI does not offer consumer media manipulation, avatar synthesis, or visual likeness generation features.
